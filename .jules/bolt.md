2024-05-20 - [ScrollController Attachment in IndexedStack], **Learning:** [When using multiple ScrollViews wrapped in an IndexedStack, they stay mounted in the widget tree. Assigning a single ScrollController to multiple mounted CustomScrollViews causes a state assertion error on scroll.], **Action:** [Provide unique ScrollControllers to each nested ScrollView inside an IndexedStack, or conditionally use them, then sync state through dedicated listeners.]
2025-02-14 - [Memoizing Expensive Getters in ChangeNotifier]
**Learning:** [When modifying `ChangeNotifier` controllers, expensive derived states (like O(N) filtered lists) must be memoized. High-level widgets use `ListenableBuilder`, causing any unrelated state change (e.g. `toggleCompactGrid`) triggering `notifyListeners()` to full rebuild and re-evaluate O(N) getters un-cached, leading to severe performance degradation.]
**Action:** [Always add a cache variable and properly invalidate it for derived state accessed through getters in a `ChangeNotifier` if `notifyListeners()` is called by unrelated state.]
